# 🇬🇧 English Learning AI Telegram Bot (SM-2 + Gemini 3 Flash + Hybrid TTS)

Production-ready асинхронный Telegram-бот для персонального изучения английского языка с алгоритмом интервальных повторений **SuperMemo-2 (SM-2)**, гибридным нейронным синтезом речи (**Microsoft Edge TTS** и **Gemini Neural TTS**), голосовым распознаванием и глубоким лингвистическим анализом через **Google Gemini API (Gemini 3.7 / 3.8 / 3.5 Flash & Flash-Lite)**.

---

## 🌟 Ключевые возможности

### 1. Universal Input Engine (Универсальный ввод слов)
- **Текст на русском или украинском:** переводит фразу в эталонное каноническое английское слово.
- **Опечатки в английском:** исправляет орфографию (например, `necesary` ➔ `necessary`) и сохраняет пометку об исходной ошибке.
- **Грамматические формы:** автоматически приводит формы слов к базовой словарной лемме (`went` ➔ `go`, `better` ➔ `good`, `running` ➔ `run`).
- **Голосовые сообщения (Telegram Voice):** нативный прием аудио `audio/ogg` (Opus) в память (`io.BytesIO`) и отправка напрямую в Gemini Flash через `types.Part.from_bytes` без временных файлов на диске.
- **Фонетика IPA (RP / GA):** четкая фиксация британского (Received Pronunciation) и американского (General American) стандартов транскрипции с первичным (`ˈ`) и вторичным (`ˌ`) ударением.
- **Оптимизация инференса:** отключение режима рассуждений (`thinking_budget: 0`) для мгновенного отклика и экономии квот токенов.
- **Проверка на дубликаты:** защищает от повторного добавления слов и лишних трат токенов, предлагая сразу повторить уже имеющееся слово.
- **Карточка слова:** подробный разбор с частью речи, IPA-транскрипцией, естественным переводом, 2–3 живыми примерами и коллокациями, а также кнопками `[🔊 Озвучить еще раз]`, `[📐 Формы]`, `[⏳ 12 Времен]`, `[🌱 Семья слов]`, `[🎭 Диалог]`, `[🗑 Удалить]`, `[✅ Знаю (в архив)]`.

### 2. Алгоритм интервальных повторений SuperMemo-2 (SM-2)
- Расчет интервалов в чистом модуле `bot/services/srs_service.py`:
  - **Успешный ответ:**
    - Шаг 1: `interval = 1` день, `repetition = 1`
    - Шаг 2: `interval = 6` дней, `repetition = 2`
    - Шаг 3+: `interval = round(interval * ease_factor)`, `repetition += 1`
  - **Провал (исчерпаны 3 попытки):**
    - `repetition = 0`, `interval = 1`, `ease_factor = max(1.3, ease_factor - 0.2)`
- Поле `next_review_at` хранится в UTC с учетом таймзон.

### 3. Интерактивный Quiz Engine (FSM)
- **4 динамических режима проверки:**
  1. **Spelling (Правописание):** ввод слова на английском по русскому переводу.
  2. **Multiple Choice (Выбор из 4 вариантов):** выбор правильного перевода с автогенерацией дистракторов.
  3. **Listening (Аудирование):** воспроизведение только голосового файла без подсказки текста.
  4. **Voice Mode (Голосовой ответ):** произнесение слова голосом в ответ на карточку — Gemini проверяет правильность произношения.
- **Механика 3 попыток и нормализация ответа:**
  - Автоматическое игнорирование регистра, крайних пробелов, знаков пунктуации, артиклей (`a`, `an`, `the`) и частицы `to`.
  - **Попытка 1 (ошибка):** подсказка первой и последней буквы с маской (`h _ _ _ o` [5 букв]).
  - **Попытка 2 (ошибка):** контекстный пример из жизни с пропуском слова (`I just called to say ___ to you`).
  - **Попытка 3 (ошибка):** демонстрация правильного ответа, сброс SM-2 интервала на 1 день и отправка свежего аудио произношения.

### 4. Фоновый шедулер и Quiet Hours (Тихие часы)
- `AsyncIOScheduler` периодически проверяет слова, готовые к повторению (`next_review_at <= now()`).
- Учет персонального часового пояса пользователя (`zoneinfo`): пуши отправляются только в дневное время (по умолчанию с 10:00 до 21:00 по местному времени).
- Защита от спама и удобная кнопка `[🧠 Начать квиз]`.

## 🛠 Технологический стек

| Компонент | Технология |
|---|---|
| Язык | Python 3.11+ |
| Бот-фреймворк | **aiogram 3.x** (Router-based, FSM, Middlewares, Inline Keyboards) |
| База данных | **MongoDB (нативный асинхронный PyMongo AsyncMongoClient)** |
| Модели данных | **Pydantic v2** |
| Шедулер | **APScheduler** (`AsyncIOScheduler`) |
| Нейронный TTS | **edge-tts** (`en-US-AriaNeural`, потоковая генерация в `io.BytesIO`) |
| LLM & STT | **Google Gemini API** (`google-genai` SDK, модель `gemini-3.5-flash-lite`, Pydantic v2 Structured Outputs) |
| Тестирование | **pytest**, **pytest-asyncio** |
| Контейнеризация | **Docker**, **Docker Compose** |

## 🚀 Быстрый старт

### 1. Клонирование репозитория и создание окружения
```bash
git clone <repo_url> english_bot
cd english_bot

python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Скопируйте `.env.example` в `.env` и укажите ваши ключи:
```bash
cp .env.example .env
```
Заполните обязательные поля:
- `BOT_TOKEN` — токен вашего Telegram-бота от [@BotFather](https://t.me/BotFather).
- `GEMINI_API_KEY` — API-ключ от [Google AI Studio](https://aistudio.google.com/).

### 3. Запуск бота локально
Убедитесь, что у вас запущен локальный сервер MongoDB (например, через Docker: `docker run -d -p 27017:27017 mongo`), затем запустите бота:
```bash
python main.py
```

## 🐳 Запуск через Docker Compose

Для продакшн-развертывания с автоматическим перезапуском и сохранением базы данных в томе:

```bash
# 1. Убедитесь, что .env заполнен
cp .env.example .env

# 2. Сборка и запуск контейнера в фоне
docker compose up -d --build

# 3. Просмотр логов
docker compose logs -f
```

Данные MongoDB будут сохраняться в volume, настроенный в `docker-compose.yml`.

| Команда | Описание |
|---|---|
| `/start` | Приветствие, краткий туториал и старт работы |
