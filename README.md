# 🌍 Multilingual AI Vocabulary & Language Learning Bot (SM-2 + Gemini 3 Flash + Hybrid TTS)

Production-ready асинхронный Telegram-бот для персонального изучения иностранных языков (английский, немецкий, испанский, французский, итальянский, польский и др.) с поддержкой различных родных языков (украинский, русский, английский и др.), мульти-словарями, алгоритмом интервальных повторений **SuperMemo-2 (SM-2)**, гибридным нейронным синтезом речи (**Microsoft Edge TTS** и **Gemini Neural TTS**), голосовым распознаванием и глубоким лингвистическим анализом через **Google Gemini API (Gemini 3.7 / 3.8 / 3.5 Flash & Flash-Lite)**.

---

## 🌟 Ключевые возможности

### 1. Мультиязычность и персональные словари (Multi-Dictionary)
- **Любые языковые пары:** выберите любой изучаемый язык (`target_language`) и родной язык интерфейса (`native_language`).
- **Несколько словарей:** бот поддерживает параллельное изучение нескольких языков (например, Английский и Немецкий) с независимыми наборами слов, статистикой и интервалами повторений.
- **Управление в меню настроек (`/settings`):** быстрое переключение активного словаря в разделе «📚 Мои словари», выбор языков, настройка скрытия перевода (`<tg-spoiler>`).
- **Интернационализация (i18n):** интерфейс бота переведен на украинский, английский, немецкий, испанский, французский, итальянский, польский и русский языки.

### 2. Universal Input Engine (Универсальный ввод слов)
- **Текст на родном или изучаемом языке:** бот автоматически понимает язык ввода. Слово на родном языке переводится в эталонное каноническое слово изучаемого языка; слово на изучаемом языке анализируется и переводится на родной язык.
- **Исправление опечаток:** нейросеть бережно исправляет орфографию (например, `necesary` ➔ `necessary`) и сохраняет пометку об исходной опечатке.
- **Грамматические формы и лемматизация:** автоматически приводит формы слов к базовой словарной лемме (`went` ➔ `go`, `besser` ➔ `gut`, `running` ➔ `run`).
- **Голосовые сообщения (Telegram Voice):** нативный прием аудио `audio/ogg` (Opus) в память (`io.BytesIO`) и отправка напрямую в Gemini Flash через `types.Part.from_bytes` без временных файлов на диске.
- **Фонетика IPA:** фиксация международной транскрипции IPA и региональных диалектов с ударениями.
- **Оптимизация инференса:** отключение режима рассуждений (`thinking_budget: 0`) для мгновенного отклика и экономии квот токенов.
- **Проверка на дубликаты:** защищает от повторного добавления слов в рамках текущего словаря, предлагая сразу повторить уже имеющееся слово.
- **Rich Messages карточка слова:** разбор с частью речи, IPA-транскрипцией, переводом, формами слова, значениями, примерами, кнопками управления и встроенным аудио `tg://audio?id=audio1`.

### 3. Алгоритм интервальных повторений SuperMemo-2 (SM-2)
- Расчет интервалов в чистом модуле `bot/services/srs_service.py`:
  - **Успешный ответ:**
    - Шаг 1: `interval = 1` день, `repetition = 1`
    - Шаг 2: `interval = 6` дней, `repetition = 2`
    - Шаг 3+: `interval = round(interval * ease_factor)`, `repetition += 1`
  - **Провал (исчерпаны 3 попытки):**
    - `repetition = 0`, `interval = 1`, `ease_factor = max(1.3, ease_factor - 0.2)`
- Поле `next_review_at` хранится в UTC с учетом таймзон.

### 4. Интерактивный Quiz Engine (FSM)
- **4 динамических режима проверки:**
  1. **Spelling (Правописание):** ввод слова на изучаемом языке по переводу на родном языке.
  2. **Multiple Choice (Выбор из 4 вариантов):** выбор правильного перевода с автогенерацией контекстных дистракторов на родном языке.
  3. **Listening (Аудирование):** воспроизведение голосового файла без подсказки текста.
  4. **Voice Mode (Голосовой ответ):** произнесение слова голосом в ответ на карточку — Gemini проверяет точность произношения.
- **Мультиязычная нормализация и 3 попытки:**
  - Автоматическое игнорирование регистра, пунктуации, специфических артиклей для каждого языка (EN: `a`, `an`, `the`; DE: `der`, `die`, `das`, `ein`; ES: `el`, `la`, `un`; FR: `le`, `la`, `l'`; IT: `il`, `lo`, `la` и др.) и инфинитивных частиц (`to `, `zu `).
  - **Попытка 1 (ошибка):** подсказка первой и последней буквы с маской (`h _ _ _ o` [5 букв]).
  - **Попытка 2 (ошибка):** пример из контекста с пропуском слова.
  - **Попытка 3 (ошибка):** демонстрация правильного ответа, сброс SM-2 интервала на 1 день и отправка аудио произношения.

### 5. Фоновый шедулер и Quiet Hours (Тихие часы)
- `AsyncIOScheduler` периодически проверяет слова, готовые к повторению (`next_review_at <= now()`).
- Учет персонального часового пояса пользователя (`zoneinfo`): напоминания отправляются только в дневное время (по умолчанию с 10:00 до 21:00 по местному времени).
- Автоматическая деактивация брошенных квизов через 30 минут неактивности.

### 6. WebApp (Telegram Mini App)
- Интерактивный личный кабинет и словарь слов в Telegram WebApp.
- Поиск по словам и переводам, фильтрация (все, к повторению, в процессе, архив), сортировка.
- Аудиовоспроизведение произношения с автовыбором голоса Edge TTS / Gemini TTS под изучаемый язык.

## 🛠 Технологический стек

| Компонент | Технология |
|---|---|
| Язык | Python 3.11+ |
| Бот-фреймворк | **aiogram 3.x** (Router-based, FSM, Middlewares, Inline Keyboards, Rich Messages API 10.1+) |
| База данных | **MongoDB (нативный асинхронный PyMongo AsyncMongoClient)** |
| Модели данных | **Pydantic v2** |
| Шедулер | **APScheduler** (`AsyncIOScheduler`) |
| Нейронный TTS | **edge-tts** (мультиязычные голоса) + **Gemini Neural TTS** |
| LLM & STT | **Google Gemini API** (`google-genai` SDK, модель `gemini-3.7-flash` / пул резервных моделей) |
| WebApp | **FastAPI** + нативный JavaScript Telegram WebApp |
| Тестирование | **pytest**, **pytest-asyncio** |
| Контейнеризация | **Docker**, **Docker Compose** |

## 🚀 Быстрый старт

### 1. Клонирование репозитория и создание окружения
```bash
git clone <repo_url> vocab_bot
cd vocab_bot

python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Скопируйте `.env.example` в `.env` и укажите ваши ключи:
```bash
cp .env.example .env
```
Заполните обязательные поля:
- `BOT_TOKEN` — токен вашего Telegram-бота от [@BotFather](https://t.me/BotFather).
- `GEMINI_API_KEY` — API-ключ от [Google AI Studio](https://aistudio.google.com/).

### 3. Запуск бота локально
Убедитесь, что у вас запущен локальный сервер MongoDB (например, через Docker: `docker run -d -p 27017:27017 mongo`), затем запустите бота:
```bash
python main.py
```

## 🐳 Запуск через Docker Compose

Для продакшн-развертывания с автоматическим перезапуском и сохранением базы данных в томе:

```bash
docker compose up -d --build

# 3. Просмотр логов
docker compose logs -f
```

## 📱 Команды Telegram-бота

| Команда | Описание |
|---|---|
| `/start` | Выбор изучаемого языка при первом входе, приветствие и старт работы |
| `/quiz` | Запуск квиза по словам активного словаря, готовым к повторению |
| `/quiz_practice` | Тренировка по всем активным словам текущего словаря вне графика |
| `/stats` | Статистика по текущему словарю: стрик, слова на изучении, архив, интервалы |
| `/settings` | Меню настроек: выбор родного и изучаемого языков, «Мои словари», скрытие перевода, часовой пояс и тихие часы |
| `/help` | Развернутое руководство по всем возможностям бота |
